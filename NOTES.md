# Operations

| Operation                   | What it does / returns                      | Rust function / CPI                                                                    | Main restriction                                          |
|-----------------------------|---------------------------------------------|----------------------------------------------------------------------------------------|-----------------------------------------------------------|
| Verify encrypted input      | Accepts an encrypted value for computation  | `fhe.verified_input::<T>(attestation)`                                                 | Valid attestation; app checks user identity               |
| Encrypt public constant     | Public constant → encrypted handle          | `fhe.trivial_encrypt(value)` or `fhe.trivial_encrypt_u64(value)`                       | Original constant remains public                          |
| Random value                | Returns an encrypted random value           | `fhe.rand::<T>()`, `fhe.rand_bounded_u64(bound)`                                       | Bounded helper uses Uint64 and a power-of-two upper bound |
| Arithmetic                  | Returns an encrypted integer                | `fhe.add(a, b)`, `.sub(a, b)`, `.mul(a, b)`, `.neg(a)`                                 | Unsigned; overflow/underflow wraps                        |
| Division / remainder        | Returns an encrypted quotient/remainder     | `fhe.div(a, b)`, `fhe.rem(a, b)`                                                       | Divisor must be public and nonzero                        |
| Multiply then divide        | Computes `(a × b) / d`                      | `fhe.mul_div(a, b, d)`                                                                 | Uint8–64; public, nonzero divisor                         |
| Comparison                  | Returns an encrypted Boolean                | `fhe.eq(a, b)`, `.ne(...)`, `.lt(...)`, `.le(...)`, `.gt(...)`, `.ge(...)`             | Ordered comparisons require integers                      |
| Minimum / maximum           | Returns the smaller/larger encrypted value  | `fhe.min(a, b)`, `fhe.max(a, b)`                                                       | Same-width operands                                       |
| Conditional selection       | Selects one encrypted value                 | `fhe.if_then_else(condition, x, y)`                                                    | Encrypted Bool condition; same-type branches              |
| Boolean / bitwise logic     | Returns an encrypted result                 | `fhe.and(a, b)`, `.or(...)`, `.xor(...)`, `.not(a)`                                    | Bool or unsigned integers                                 |
| Shifts / rotations          | Returns a shifted/rotated encrypted integer | `fhe.shl(a, b)`, `.shr(...)`, `.rotl(...)`, `.rotr(...)`                               | Shift amount may be encrypted or public                   |
| Cast                        | Converts to another integer type            | `fhe.cast::<From, To>(value)`                                                          | Destination must be a different unsigned type             |
| Aggregate sum               | Returns an encrypted total                  | `fhe.sum(values)`                                                                      | Maximum 100 Uint8–32 or 60 Uint64–128 operands            |
| Membership                  | Returns an encrypted Boolean                | `fhe.is_in(value, set)`                                                                | Same-type integers; same 100/60 limits                    |
| Store result                | Writes a handle into a named slot           | `fhe.output(value, store.set(key))`                                                    | Store authority must sign                                 |
| Grant private decryption    | Permits a viewer to decrypt a fresh result  | `store.set(key).allow(viewer)` passed to `fhe.output(...)`                             | Applies to that exact handle                              |
| Grant temporary computation | Shares a fresh result with another Store    | `store.result().allow_transient(consumer)` passed to `fhe.output(...)`                 | Transaction only; consumer authority signs                |
| Allow public decryption     | Publishes permission to decrypt a result    | Output `.make_public()`; current slot: `zama_host::cpi::make_store_handle_public(...)` | Store authority must sign                                 |
| Verify public plaintext     | Validates a decrypted result on-chain       | `zama_host::cpi::verify_public_decrypt(...)`                                           | KMS certificate + public-permission proof                 |
